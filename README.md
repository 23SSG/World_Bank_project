📊 Leveraging World Bank Support: Empowering Ghana's Economic Transformation
🎯 Objective

The objective of this project is to demonstrate how SQL can be applied to a real-world economic challenge—specifically, analyzing Ghana’s economic transformation under World Bank support. Through structured querying and data exploration, the project aims to uncover actionable insights related to World Bank–funded initiatives, their scale, and their impact on the country's development.

📘 Project Overview

This project highlights the power of SQL in extracting meaningful insights from complex development datasets. By analyzing World Bank data related to Ghana, SQL enabled efficient filtering, aggregation, and exploration of key economic indicators and funded programs.

One of the major findings of this analysis was the identification of 198 World Bank–funded projects that have contributed significantly to Ghana’s economic progress. These initiatives span sectors such as infrastructure, energy, financial stability, and social development—demonstrating how external support can strengthen national growth.

The analysis also surfaced the top funded projects under the International Development Association (IDA), including:

Ghana: Sankofa Gas Project

GH–Macroeconomic Stability for Competitive and Growth Project

First Resilient Recovery Development Policy Financing

Ghana Development Finance Project

Overall, this work reinforced the value of SQL as a powerful tool for real-world data analysis and evidence-based decision-making.
